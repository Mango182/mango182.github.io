# mango182.github.io

Portfolio site for Miguel Echeverry

**Live site:** https://mango182.github.io

## Built with

- React + TypeScript
- Vite
- Tailwind CSS (styling)
- Formspree (contact form)
- Deployed to GitHub Pages via `gh-pages`

## Running locally

Requires Node.js.

```bash
git clone https://github.com/Mango182/mango182.github.io.git
cd mango182.github.io
npm install
npm run dev
```

Then open the local URL Vite prints

## Deploying

```bash
npm run deploy
```

This builds the site into `dist/` and publishes it to the `gh-pages` branch, which GitHub Pages serves.
